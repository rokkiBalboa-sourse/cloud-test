# Веб-платформа тестирования: «Облачные технологии»

Облегчённый отборочный практикум на 40–45 минут для выявления кандидатов в команду по компетенции **«Облачные технологии»**.

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей (один раз)
```bash
npm install
```

### 2. Сборка фронтенда
```bash
npm run build
```

### 3. Запуск сервера
```bash
npm start
```

После этого откройте в браузере: **`http://localhost:3000`**

*(Или через Docker: `docker compose up -d`)*

---

## 👥 Учетные записи

| Роль | Логин | Пароль | Описание |
|---|---|---|---|
| **Преподаватель / Эксперт** | `admin` | `admin2027` | Панель админа, просмотр всех показателей и исходного кода, экспорт CSV |

## 📋 Структура модулей (40–45 минут, 100 баллов)

### Модуль 1. Поиск ошибок в конфигурации Nginx и фильтрация логов (25 б.)
- **Задача 1.1 (15 б.):** Исправление сбойного файла `/etc/nginx/nginx.conf` (пропущенная точка с запятой в `proxy_pass` и опечатка в `stub_status on;`).
- **Задача 1.2 (10 б.):** Интерактивная фильтрация журнала `/var/log/syslog` с помощью команды `grep` / регулярного выражения по статусу `[CRITICAL]` и компоненту `kernel`.

### Модуль 2. Dockerfile и логика CI/CD (25 б.)
- **Задача 2.1 (15 б.):** Написание `Dockerfile` с нуля по ТЗ (alpine:3.19, `apk add --no-cache nginx`, копирование html, порт 80, запуск на foreground).
- **Задача 2.2 (10 б.):** Исправление ошибки версионирования в `.gitlab-ci.yml` (запуск собранного `app:$CI_PIPELINE_IID` вместо `app:latest`).

### Модуль 3. Идемпотентность и синтаксис Ansible Playbook (25 б.)
- **Задача 3.1 (25 б.):** Поиск и исправление ошибок в плейбуке `prepare.yml` (использование официального FQCN модуля `ansible.posix.sysctl`, корректный синтаксис и задача отключения swap).

### Модуль 4. Архитектурный тест (Сетевой стек, порты и компоненты) (25 б.)
- **Задача 4.1 (25 б.):** Интерактивное сопоставление ключевых компонентов и их сетевых портов по умолчанию:
  * Kubernetes API Server: `6443`
  * Grafana Web UI: `3000`
  * Prometheus API / UI: `9090`
  * Loki Log Receiver: `3100`
  * Tempo OTLP gRPC: `4317`
  * HAProxy K8s VIP Frontend: `7443`
  * Grafana Mimir Remote Write: `9009`

## 🎯 Автоматическая оценка и админка (`/admin`)

- Все показатели мгновенно рассчитываются на сервере и падают в ведомость.
- Студент видит экран благодарности без раскрытия правильных ответов.
- Повторное прохождение теста заблокировано.
- Экспорт сводной ведомости в Excel (CSV UTF-8).
- Полный справочник ответов доступен в файле **`ANSWERS_KEY.md`**.
